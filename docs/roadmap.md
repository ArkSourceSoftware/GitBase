# GitBase Roadmap

This roadmap outlines planned improvements and future features for GitBase.

> Development priorities may change based on user feedback, technical requirements, and project direction.

## Available Features

- Repository creation and management
- Branch management
- Pull request workflow
- Issue tracking
- User authentication and account management
- Local network Git hosting
- Snapshot backup and restore system

## Planned Improvements

### Improved Collaboration

- Activity feeds for repository updates
- More configurable notifications for repository activity, pull requests, issues, and releases
- Improved collaboration workflows

### Repository Management

- Version tagging and release management improvements
- Automated release notes
- Repository archiving tools

### Security Improvements

- Two-factor authentication
- Improved access auditing
- Additional repository security options

### Backup and Recovery

- Scheduled automatic snapshots
- Improved snapshot management and backup workflows
- Improved recovery workflows

## Under Consideration

Features being evaluated based on user feedback:

- Additional authentication options
- More repository integrations
- Additional Git workflow improvements
- Additional automation tools
- AI-assisted development features

Feedback from GitBase users helps shape future improvements. If you have ideas or feature requests, please share them through [GitBase Discussions](../../discussions).
