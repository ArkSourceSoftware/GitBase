# Users Documentation

## Overview

GitBase supports multiple user types with distinct capabilities and access levels. The permission system is designed to accommodate diverse organizational structures, from personal projects to teams managing hundreds of repositories.

## User Registration

### Creating an Account
To create a new GitBase account:

1. Navigate to the GitBase website and click **Sign Up**
2. Enter your required information:
   - Username
   - Display name
   - Email address (must be unique in GitBase)
   - Password (minimum 16 characters with uppercase, lowercase, number)
   - Display bio (optional)
3. Once registered, you can sign in and complete your profile setup (avatar, bio, preferences)

## Profile Management

### Editing Your Profile
1. Navigate to **Settings** from the main menu
2. Select **Profile** tab
3. Make changes to:
   - Display name and bio
   - Personal web address
   - Social accounts


## Administrator Accounts

GitBase supports multiple administrator accounts, but at least one administrator account must always exist.

### Creating an Administrator Account

1. In the GitBase application, tap the **+** button at the bottom of the screen and select **New User**.
2. Enter the required information:
   - Username
   - Display name
   - Email address (must be unique within GitBase)
   - Password (minimum 16 characters, including uppercase letters, lowercase letters, and numbers)
   - Display bio (optional)
3. Under **User Type**, select **Administrator**.
4. Tap **Create** to create the administrator account.
