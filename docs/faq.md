# <img src="../assets/icon.png" width="25" height="25" alt="GitBase"> Frequently Asked Questions

### 🔹What is GitBase?
GitBase is a private, self-hosted Git collaboration platform that runs directly on Android devices. It allows you to host Git repositories, manage development workflows, review changes, track issues, and collaborate through a built-in web interface — without relying on external hosting services.

GitBase gives developers a lightweight alternative for managing their own source code infrastructure while keeping their data under their own control.

<hr style="height:1px;border:none;background-color:currentColor;opacity:0.2;">

### 🔹Why would I use GitBase?
GitBase is designed for developers who want a private and portable Git hosting solution that they can run anywhere.

Whether you are managing personal projects, experimenting with new ideas, working with a small team, or need access to your repositories while away from a traditional development environment, GitBase provides a complete Git collaboration experience directly from your Android device.

<hr style="height:1px;border:none;background-color:currentColor;opacity:0.2;">

### 🔹Does GitBase require an internet connection?
No. GitBase can operate entirely on your local network or device.

You can host repositories and access the built-in web interface without an external internet connection. If your device is connected to a network, other authorized users can access GitBase remotely through that network.

<hr style="height:1px;border:none;background-color:currentColor;opacity:0.2;">

### 🔹Where is my repository data stored?
Your repositories are stored directly on your Android device.

GitBase does not upload your source code to external servers or require third-party cloud storage. Your data remains on your own hardware and is managed by GitBase locally.

<hr style="height:1px;border:none;background-color:currentColor;opacity:0.2;">

### 🔹Can I access GitBase from another device?
Yes.

GitBase includes a built-in web interface that allows you to access and manage your repositories from a web browser.

Any compatible device connected to the same network can interact with your GitBase instance, allowing you to manage your projects from computers, tablets, or other devices.

<hr style="height:1px;border:none;background-color:currentColor;opacity:0.2;">

### 🔹Does GitBase work with standard Git tools?
Yes.

GitBase is built around standard Git workflows. You can continue using familiar Git commands and Git-compatible development tools to clone, commit, push, pull, and manage repositories.

<hr style="height:1px;border:none;background-color:currentColor;opacity:0.2;">

### 🔹Can I use GitBase for collaboration?
Yes.

GitBase supports collaboration between multiple users when your Android device is accessible on a network.

It can be used for small development teams, private projects, internal tools, or situations where you want to host your own Git infrastructure without depending on external services.

<hr style="height:1px;border:none;background-color:currentColor;opacity:0.2;">

### 🔹Is my source code uploaded anywhere?
No.

Your repositories remain on your device. GitBase is designed around a local-first approach, keeping your source code and project data under your control.

Network communication only occurs when you or authorized users connect to your GitBase instance.

<hr style="height:1px;border:none;background-color:currentColor;opacity:0.2;">

### 🔹What devices can run GitBase?
GitBase is designed to run on modern Android devices.

Performance depends on your device hardware, available storage, memory, and repository size. Devices with more resources will provide better performance when hosting larger projects.

<hr style="height:1px;border:none;background-color:currentColor;opacity:0.2;">

### 🔹Can GitBase run while I use other applications?
Yes.

GitBase can continue running as a background service, allowing your device to host repositories while you perform other tasks.

The Android system notification helps you monitor the active GitBase service and server status.

<hr style="height:1px;border:none;background-color:currentColor;opacity:0.2;">

### 🔹Can I use GitBase without creating an account?
Yes.

GitBase is designed to operate directly on your own device without requiring an external account or online service.

Your Git repositories and project management data remain associated with your local GitBase installation.

<hr style="height:1px;border:none;background-color:currentColor;opacity:0.2;">

### 🔹Does GitBase support private repositories?
Yes.

GitBase is designed for private repository hosting, allowing you to manage your own projects and control who can access them.

<hr style="height:1px;border:none;background-color:currentColor;opacity:0.2;">

### 🔹Can I migrate repositories between GitBase and other Git platforms?
Yes.

Because GitBase uses standard Git repositories, your repositories can be transferred using normal Git workflows.

You can move repositories between GitBase and other Git hosting platforms that support standard Git repositories.

<hr style="height:1px;border:none;background-color:currentColor;opacity:0.2;">

### 🔹Does GitBase replace Git itself?
No.

GitBase is built around Git and provides hosting and collaboration features on top of Git repositories.

Git remains the underlying version control system used to track changes, branches, commits, and project history.

<hr style="height:1px;border:none;background-color:currentColor;opacity:0.2;">

### 🔹Is GitBase open source?
No.

GitBase is distributed as closed-source commercial software.

The application source code is not publicly available. GitBase uses established open-source technologies and libraries where appropriate, while the core application remains proprietary.
